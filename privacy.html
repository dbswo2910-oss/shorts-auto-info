인증 토큰과 API 키는 운영자 PC의 Git 제외 환경 파일 및 비공개 저장소의 GitHub Actions Secrets에 보관합니다. 일반 소스 코드나 공개 웹페이지에 포함하지 않습니다. 제작 파일, 분석 결과, 게시 기록은 운영자 PC와 구성된 비공개 GitHub 작업 기록·상태 저장소에 보관합니다. 현재 제작 artifact는 7일 보관 설정이며 로컬 결과와 상태 기록은 운영자가 삭제할 때까지 남을 수 있습니다. 플랫폼 자체에 게시된 콘텐츠의 보관은 해당 플랫폼에서 관리합니다.

Google·YouTube, Meta·Instagram은 인증, 데이터 조회와 게시 요청을 처리합니다. GitHub는 비공개 자동 실행 및 저장을 제공합니다. 설정된 Gemini API에는 콘텐츠 분석을 위해 채널 게시물 정보와 기본 통계, 제작 기록이 전달될 수 있습니다. 원래의 비밀 인증 키·토큰은 분석 프롬프트에 넣지 않습니다. 제작 작업에 따라 OpenAI, Anthropic, Higgsfield, Typecast 등의 API로 대본·프롬프트·제작 미디어가 전송됩니다. 각 제공자의 데이터 처리·보관 조건도 적용됩니다.
